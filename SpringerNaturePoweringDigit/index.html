Tool · ProvenanceFaultTree

Fault Tree Analysis

Systems Analysis Complexity

Fault tree analysis that refuses to run on numbers with no source. The classical method (Vesely et al., NUREG-0492, 1981) with one layer added: every probability arrives with its origin, and every gate records who put it there.

Tool · ProvenanceEventTree

Event Tree Analysis

Systems Analysis Complexity

Event tree analysis, forwards from an initiating event through each safety barrier to its end states. The classical method (Rasmussen, WASH-1400, 1975) with the same evidence layer: every end state carries the weakest evidence behind it.
